Welcome to the feature showcase! This blog is designed to be highly readable, strongly typographic, and ultra-fast. It fully supports [standard Markdown rendering](https://ezioleq.com), alongside rich interactive components via MDX.

<Sidenote>
  Marginalias (Sidenotes) appear here on large screens and wrap below standard text blocks on mobile devices. They're excellent for providing context without breaking flow!
</Sidenote>

## Text and Typography

We prioritize system fonts for performance and a native feel. You'll notice simple, high-contrast dark-mode typography (or light mode depending on your toggle).

Here is a blockquote:
> Software development is an exercise in managing complexity. Keep things simple natively, and you avoid creating problems to solve.

## Custom Components

Beyond standard Markdown, we've enabled three distinct MDX elements.

### Colorized Callouts

Use Callouts to draw attention to critical information:

<Callout type="info" title="Information">
  Astro allows us to weave React-like components directly into our markdown without shipping JavaScript to the client!
</Callout>

<Callout type="warning" title="Watch out!">
  Remember to close your MDX tags. Unlike standard markdown, MDX will fail the build if you leave tags unclosed.
</Callout>

<Callout type="error" title="Something went wrong">
  This is an error callout.
</Callout>

### Foldable Areas

If you have supplementary information that shouldn't take up visual space initially, use the Foldable component!

<Foldable title="Click to unveil hidden secrets">
  You found me! This area uses native HTML details and summary under the hood, ensuring it works perfectly even before any JavaScript runs, although we styled it nicely to match the theme.

  <Callout type="info" title="Information">
    Callout inside foldable element
  </Callout>

  Testing test of text on the end of an foldable element.
</Foldable>
